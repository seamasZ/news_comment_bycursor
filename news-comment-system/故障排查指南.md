# 故障排查指南

## "生成失败，请检查URL是否正确或稍后重试" 错误

### 步骤1：检查后端服务是否运行

在浏览器中访问：http://localhost:8000/docs

**如果无法访问：**
- 后端服务没有运行
- 解决方案：在新的 PowerShell 窗口中运行：
  ```powershell
  cd news-comment-system\backend
  .\venv\Scripts\Activate.ps1
  python main.py
  ```
- 应该看到类似输出：`Uvicorn running on http://0.0.0.0:8000`

### 步骤2：检查前端是否连接到正确的后端

前端默认连接到：`http://localhost:8000`

**如果后端运行在不同的端口：**
- 修改 `frontend/src/App.jsx` 中的 `API_BASE` 常量

### 步骤3：检查浏览器控制台错误

1. 打开浏览器开发者工具（按 F12）
2. 切换到 "Console"（控制台）标签页
3. 查看是否有红色错误信息
4. 查看 "Network"（网络）标签页，检查 API 请求是否成功

### 步骤4：检查新闻URL

确保：
- URL 格式正确：`https://example.com/news/article`
- URL 是公开可访问的（不需要登录）
- URL 是有效的新闻文章链接
- 某些网站可能有反爬虫机制，尝试使用其他新闻网站

### 步骤5：检查API配置

检查 `backend/.env` 文件：
```env
OPENAI_API_KEY=你的API密钥
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_MODEL=deepseek-chat
```

**验证API密钥：**
- 访问 DeepSeek 控制台检查 API 密钥是否有效
- 检查是否有足够的免费额度

### 步骤6：查看后端日志

后端运行时会显示详细错误信息，查看终端输出：
- 如果看到具体的错误信息，根据错误信息进行修复
- 常见错误：
  - `提取新闻内容失败` - URL 无法访问或提取失败
  - `OpenAI client not available` - API 配置有问题
  - `网络错误` - 网络连接问题

### 步骤7：测试新闻URL

尝试使用以下测试URL（如果可访问）：
- 简单的新闻网站文章链接
- 确保URL可以直接在浏览器中打开并显示新闻内容

## 常见错误解决方案

### 错误：无法连接到服务器
- **原因**：后端服务没有运行
- **解决**：启动后端服务

### 错误：HTTP 403 错误：网站拒绝访问（可能是反爬虫机制）
- **原因**：
  1. 网站检测到爬虫访问，触发了反爬虫机制
  2. 某些大型新闻网站（如搜狐、新浪等）有严格的反爬虫策略
  3. IP 被临时封禁
- **解决**：
  1. **推荐**：使用对爬虫友好的新闻网站，例如：
     - 新华网（www.xinhuanet.com）
     - 人民网（www.people.com.cn）
     - 光明网（www.gmw.cn）
  2. 避免使用以下可能有严格反爬虫的网站：
     - 搜狐（sohu.com）
     - 新浪（sina.com.cn）
     - 网易（163.com）
  3. 代码已自动添加浏览器请求头，但某些网站仍可能阻止访问

### 错误：提取的内容过短，可能不是有效的新闻文章
- **原因**：
  1. URL指向的不是新闻文章页面（可能是首页、分类页等）
  2. 网站有反爬虫机制阻止了内容提取
  3. 页面需要JavaScript动态加载内容
  4. 网站结构特殊，无法自动识别文章内容
- **解决**：
  1. 确保URL是具体的新闻文章链接（不是首页或列表页）
  2. 尝试使用其他新闻网站的URL
  3. 确保URL是公开可访问的（不需要登录）
  4. 推荐使用对爬虫友好的新闻网站（如新华网、人民网等）

### 错误：API调用失败
- **原因**：API密钥无效或额度不足
- **解决**：检查并更新API密钥，确认有足够额度

### 错误：网络错误
- **原因**：网络连接问题或防火墙阻止
- **解决**：检查网络连接，临时关闭防火墙测试

## 调试技巧

1. **使用浏览器开发者工具**：
   - F12 打开开发者工具
   - 查看 Network 标签页，检查 API 请求的响应

2. **查看后端日志**：
   - 后端终端会显示所有请求和错误信息
   - 根据错误信息定位问题

3. **测试API端点**：
   - 访问 http://localhost:8000/docs
   - 在 Swagger UI 中直接测试 API

4. **检查环境变量**：
   - 确认 `.env` 文件在 `backend` 目录下
   - 确认环境变量名称和值正确
