# 国内免费大模型配置指南

## 推荐配置（免费或免费额度）

本系统支持所有兼容 OpenAI API 格式的大模型，以下是国内常用免费大模型的配置方法：

### 1. DeepSeek（推荐，免费额度充足）

**注册地址**：https://platform.deepseek.com/api_keys

**配置**：
```env
OPENAI_API_KEY=你的deepseek_api_key
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_MODEL=deepseek-chat
```

**特点**：
- 免费额度充足
- 完全兼容 OpenAI API 格式
- 响应速度快
- 中文支持好

### 2. Moonshot（免费额度）

**注册地址**：https://platform.moonshot.cn/console/api-keys

**配置**：
```env
OPENAI_API_KEY=你的moonshot_api_key
OPENAI_BASE_URL=https://api.moonshot.cn/v1
OPENAI_MODEL=moonshot-v1-8k
```

**特点**：
- 有免费额度
- 中文支持优秀
- 支持长文本

### 3. 智谱AI GLM（免费额度）

**注册地址**：https://open.bigmodel.cn/usercenter/apikeys

**配置**：
```env
OPENAI_API_KEY=你的zhipu_api_key
OPENAI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
OPENAI_MODEL=glm-4
```

**特点**：
- 有免费额度
- 中文支持优秀
- 性能稳定

### 4. 通义千问（阿里云，免费额度）

**注册地址**：https://dashscope.console.aliyun.com/apiKey

**配置**：
```env
OPENAI_API_KEY=你的qianwen_api_key
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
OPENAI_MODEL=qwen-turbo
```

**特点**：
- 阿里云提供
- 有免费额度
- 稳定性好

### 5. 百度文心一言（需要自行适配）

如果文心一言不支持 OpenAI 兼容格式，可以修改代码直接调用其API。

## 配置步骤

1. 选择一个平台，注册账号并获取 API Key
2. 在 `backend` 目录下创建 `.env` 文件
3. 复制对应平台的配置到 `.env` 文件
4. 替换 `your_xxx_api_key` 为你的实际 API Key
5. 保存文件，重启后端服务

## 测试配置

配置完成后，可以运行后端服务测试：

```bash
python main.py
```

访问 http://localhost:8000 查看 API 文档，如果配置正确，生成功能应该可以正常工作。

## 注意事项

1. **API Key 安全**：不要将 `.env` 文件提交到 Git
2. **免费额度**：注意各平台的免费额度限制
3. **模型名称**：确保使用的模型名称正确
4. **网络**：某些平台可能需要特定的网络环境

## 推荐使用

对于国内用户，**推荐使用 DeepSeek**，因为：
- 免费额度最充足
- 完全兼容 OpenAI API，无需修改代码
- 中文理解能力强
- 配置最简单
